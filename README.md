# NIJISANJI 7colors · 친구와 대전

비공식 팬 제작 카드 게임 프로토타입입니다. 카드 이미지와 캐릭터의 권리는 각 권리자에게 있습니다. 공식 게임·공식 판정 서비스가 아닙니다.

## 온라인 대전

1. 같은 사이트에서 **온라인 2인**을 선택합니다.
2. 방장은 덱을 고르고 **방 만들기**를 누릅니다.
3. **초대 링크 복사**로 링크를 공유하거나 8자리 방 코드를 알려줍니다.
4. 친구는 덱을 선택하고 **방 참여**를 누릅니다.
5. 양쪽이 **준비 완료**, 방장이 **선후공 결정하고 시작**을 누릅니다. 동점 주사위는 다시 굴립니다.

내 카드를 클릭하거나 드래그해 플레이합니다. 메인에는 손패·필드로 비용을 내고, 세트에는 손패 한 장을 세트합니다. 액션에는 내 액티브 유닛을 클릭해 컬러 콜을 선택하거나 상대 레스트 유닛을 클릭해 배틀합니다. 블로커 등 선택창의 **필드 보기**로 창을 최소화할 수 있습니다.

상대에게는 손패·세트 카드의 정체와 뒷면 컬러를 보내지 않습니다. 자기 세트 카드만 본인 화면에서 확인할 수 있습니다. 선택·비용·차례·상태 번호는 방장 측 게임 엔진에서 검사합니다.

## 접속 조건

- 웹사이트는 GitHub Pages, 연결 중개는 PeerJS Cloud, 대전 통신은 WebRTC를 사용합니다. PeerJS 1.5.5를 파일로 포함했습니다.
- 방장이 대전 중 접속을 유지해야 합니다. 나가기·새로고침·연결 종료 시 진행 중인 대전은 복구되지 않습니다.
- 일부 회사·학교망 및 NAT 환경에서는 연결이 되지 않을 수 있습니다. 다른 네트워크로 시도하거나 별도 TURN 구성이 필요합니다.
- WebRTC 연결 상대에게 네트워크 주소가 알려질 수 있습니다. 방 코드를 아는 한 사람이 참가하는 친구 대전용이며 로그인·랭크·재접속·중앙 서버 부정행위 방지는 제공하지 않습니다. 방장은 전체 게임 상태를 관리하므로 서로 신뢰하는 사람과 플레이하세요.
- 카드 효과와 승패는 현재 프로젝트의 적용 규칙을 따릅니다. 자동 테스트 통과가 공식 규칙 전부의 정확성을 보증하지 않습니다.

## GitHub Pages 배포

공개 저장소의 **Settings → Pages → Source → GitHub Actions**를 선택합니다. `main`에 커밋하면 테스트·정적 파일 준비·배포가 순서대로 실행됩니다. **Actions → Publish game**이 완료되면 Pages 주소가 표시됩니다. 유료 도메인이나 상시 게임 서버를 요구하지 않습니다.

공개 배포에는 실행 파일·가공된 카드 이미지·연결 라이브러리·관련 설명만 포함합니다. 원본 첨부 파일, 개인 설정, 대용량 시뮬레이션 원자료는 포함하지 않습니다.
