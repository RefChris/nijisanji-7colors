# NIJISANJI 7colors · 친구와 대전

비공식 팬 제작 카드 게임 프로토타입입니다. 카드 이미지와 캐릭터의 권리는 각 권리자에게 있습니다. 공식 게임·공식 판정 서비스가 아닙니다.

## 온라인 대전

1. 사이트에서 **로비**를 눌러 매칭 전용 페이지(`lobby.html`)로 이동합니다.
2. 방장은 덱을 고르고 **방 만들기**를 누릅니다.
3. **공개 방 목록에 표시**를 켜면 다른 방문자가 방 코드를 몰라도 목록의 **참가** 버튼으로 들어올 수 있습니다. 비공개 코드 방은 이 옵션을 끕니다.
4. 초대 링크 또는 8자리 코드를 통한 **방 참여**도 계속 사용할 수 있습니다.
5. 양쪽이 **준비 완료**, 방장이 **선후공 결정하고 시작**을 누릅니다. 동점 주사위는 다시 굴립니다.

내 카드를 클릭하거나 드래그해 플레이합니다. 메인에는 손패·필드로 비용을 내고, 세트에는 손패 한 장을 세트합니다. 액션에는 내 액티브 유닛을 클릭해 컬러 콜을 선택하거나 상대 레스트 유닛을 클릭해 배틀합니다. 블로커 등 선택창의 **필드 보기**로 창을 최소화할 수 있습니다.

상대에게는 손패·세트 카드의 정체와 뒷면 컬러를 보내지 않습니다. 자기 세트 카드만 본인 화면에서 확인할 수 있습니다. 선택·비용·차례·상태 번호는 방장 측 게임 엔진에서 검사합니다.

스타트 페이즈에 손패가 5장 미만이면 5장까지 보충하고, 정확히 5장이면 1장을 뽑습니다. 각 플레이어 첫 턴의 스타트 생략은 유지됩니다. 컬러가 없는 라이버도 컬러 콜을 선언할 수 있으며, 상대 컬러를 공개하고 레스트되지만 색이 일치하지 않아 니지 에리어로 이동시키지 않습니다. 블로커와 컬러 콜 금지 효과는 동일하게 적용됩니다.

## 온라인 제한 시간

각 플레이어가 5분으로 시작합니다. 현재 행동하거나 효과·블로커 등을 선택해야 하는 플레이어의 시간만 차감됩니다. 자신의 턴을 완료할 때마다 30초를 추가하며, 페이즈 이동에는 추가하지 않습니다. 0초가 되면 시간 초과 패배합니다. 시계는 각 플레이 영역 오른쪽 위에 표시됩니다. AI 및 로컬 대전에는 적용하지 않습니다.

방장의 단조 증가 시계를 기준으로 경과 시간을 계산합니다. 시간 갱신 패킷은 카드 선택창을 다시 만들지 않습니다. 브라우저의 백그라운드 처리 지연이 있어도 다음 처리 시 실제 경과 시간을 반영하고, 시간 초과 후 도착한 행동은 거절합니다.

## 공개 방 목록

별도 영구 서버 없이 접속 중인 브라우저가 공개 목록을 중계합니다. 중계 브라우저가 나가면 남은 브라우저가 중계 역할을 다시 맡고 대기 중인 방을 재등록합니다. 재연결 중에는 목록이 잠시 비어 보일 수 있습니다. 참가자가 들어온 방이나 나간 방은 목록에서 제거됩니다. 공개 목록에는 방 이름·사용 덱·방 코드만 전달하며 손패나 대전 상태는 전달하지 않습니다. 방 이름은 공개되므로 공개할 내용만 입력하세요.

## 접속 조건

- 웹사이트는 GitHub Pages, 연결 중개는 PeerJS Cloud, 대전 통신은 WebRTC를 사용합니다. PeerJS 1.5.5를 파일로 포함했습니다.
- 방장이 대전 중 접속을 유지해야 합니다. 나가기·새로고침·연결 종료 시 진행 중인 대전은 복구되지 않습니다.
- 일부 회사·학교망 및 NAT 환경에서는 연결이 되지 않을 수 있습니다. 다른 네트워크로 시도하거나 별도 TURN 구성이 필요합니다.
- WebRTC 연결 상대에게 네트워크 주소가 알려질 수 있습니다. 로그인·랭크·재접속·중앙 서버 부정행위 방지는 제공하지 않습니다. 방장은 전체 게임 상태를 관리하는 비공식 캐주얼 대전입니다.
- 카드 효과와 승패는 현재 프로젝트의 적용 규칙을 따릅니다. 자동 테스트 통과가 공식 규칙 전부의 정확성을 보증하지 않습니다.
