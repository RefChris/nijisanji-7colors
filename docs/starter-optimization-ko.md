# 스타터 덱 시뮬레이션 개선 결과

현재 게임 규칙과 같은 AI를 양쪽에 사용했다. 모든 대전은 선후공을 교대했다. 채널과 컬러는 고정, 메인 50장, 같은 번호 최대 4장, 각 스타터에 등록된 15종 안에서만 구성했다. 멀리건은 사용하지 않았다.

총 144,864판. 3차례 후보 탐색 뒤 선정용 검증을 거쳤으며, 마지막 비교는 탐색·선정에 쓰지 않은 시드로 진행했다. 전역 최적해를 증명한 것이 아니라 탐색한 후보 중 선택한 구성이다. 원본 구성과 시뮬레이션 원자료는 보존했다.

최대 4장 조건에서 가능한 수량 조합은 스타터마다 1,786,941개다. 전체를 전수 조사하지 않았으며, 여러 단계로 표본을 늘리는 후보 선별과 3차례 상호 대응 탐색을 사용했다. 미토·사사키는 이전 유력 후보를 더 큰 표본으로 재비교한 뒤 기존 선정 후보를 유지했다.

## 같은 기존 상대 덱에 대한 최종 비교

다른 두 스타터의 **기존 구성**을 동일 비중으로 상대했다. 각 버전 2,000판(상대별 선공 500판·후공 500판).

|덱|기존 구성|개선 구성|변화|변화의 95% 구간|
|---|---:|---:|---:|---:|
|쿠즈하 스타터|35.6%|46.3%|+10.7%p|+8.2 ~ +13.3%p|
|츠키노 미토 덱|68.4%|70.9%|+2.6%p|-0.1 ~ +5.2%p|

개선 덱 대 같은 스타터의 기존 덱(각 1,000판): 쿠즈하 스타터 64.9% / 츠키노 미토 덱 56.2% / 사사키 사쿠 덱 56.8%.

## 범위와 검증

- 기존 구성과 개선 구성을 같은 상대·같은 셔플 시드·같은 선후공으로 비교했다. 95% 구간은 같은 시드의 교대 대전을 묶어 5,000회 재표집했다.
- 현재 AI의 덱 활용 능력과 미구현 제한의 영향이 포함된다. 특히 [한정: 동일]은 기존 구현처럼 표기만 보존되어 있다. 공식 규칙 전체를 검증한 결과나 사람 간 대전 승률은 아니다.
- 덱 수량만 변경했다. 게임 규칙, 카드 효과와 AI 평가식은 탐색을 위해 변경하지 않았다.
- 새 구성을 사용하려면 게임을 새로고침한 뒤 새 대전을 시작한다. 진행 중인 대전에는 적용하지 않는다.
